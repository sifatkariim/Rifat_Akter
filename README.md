## GitHub-এ আপলোড ও Vercel-এ লাইভ লিঙ্ক নেওয়ার নিয়ম

> দ্রষ্টব্য: পোর্টফোলিওর সব আসল ছবি ইতিমধ্যেই `assets/` ফোল্ডারে অপ্টিমাইজ করে রাখা হয়েছে, তাই GitHub-এ আপলোড করার সময় কাঁচা স্ক্রিনশটের `pictures/` ফোল্ডার বা `serve.ps1` আপলোড করার প্রয়োজন নেই (`.gitignore`-এ এগুলো বাদ দেওয়া আছে)।

### ধাপ ১: GitHub-এ আপলোড
1. [github.com](https://github.com)-এ লগইন করে **`+`** $\rightarrow$ **New repository** খুলুন (নাম দিতে পারেন `rifat-akter-portfolio`, Public রাখুন)।
2. **uploading an existing file** লিংকে ক্লিক করুন।
3. `c:\Users\USER\Downloads\Rifat Akhter` ফোল্ডার থেকে নিচের ফাইল/ফোল্ডারগুলো সিলেক্ট করে ড্র্যাগ করুন:
   - `index.html`
   - `style.css`
   - `script.js`
   - `vercel.json`
   - `Md. Rifat Akter cv.pdf`
   - `README.md`
   - `assets` ফোল্ডার
4. নিচে **Commit changes** বাটনে ক্লিক করুন।

### ধাপ ২: Vercel-এ লাইভ করা
1. [vercel.com](https://vercel.com)-এ গিয়ে **Continue with GitHub** দিয়ে সাইন ইন করুন।
2. **Add New...** $\rightarrow$ **Project** ক্লিক করুন এবং আপনার `rifat-akter-portfolio` রিপোজিটরি **Import** করুন।
3. কোনো সেটিংস পরিবর্তন না করে **Deploy** ক্লিক করুন—কিছু সেকেন্ডেই লাইভ লিঙ্ক (`https://your-project.vercel.app`) পেয়ে যাবেন।
